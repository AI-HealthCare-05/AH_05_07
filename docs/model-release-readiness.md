# SK7 모델 출시 준비 판정 계약 초안

Issue #221에서 작성한 출시 준비 초안을 고도화 Issue #230에서 구체화한다.
이번 설계 기준은 PR #227 병합 `c46c772486a30319e594dbb9cf555263d5fba1a9`이다.
현재 validation 결과를 **이미 본 뒤** 작성한 계약이며, 기존 결과를 보기 전에
정한 기준이라고 주장하지 않는다. 문서 승인과 모델 선택·test 실행·직렬화·운영
출시 승인은 각각 별도다. 새 수치 통과선을 만들지 않는다. 1회차는 진행 중이며
[발주 범위 질의](mvp1-closeout.md#발주사-확인용-질의-초안--미발송)는 미발송이다.

## 목적 선택: 현재 계약과 후속 경로

**확정**은 현재 저장소의 보존 계약, **제안**은 검토 가능한 후속 경로,
**미정**은 근거나 사람 결정이 없어 실행할 수 없는 부분이다. 제안의 문서 병합은
데이터 접근·모델 실행이나 발주 범위 변경 승인이 아니다.

| 경로 | 제공하려는 결과 / 현재 가능 범위 | 데이터와 구현 요구 | 평가 및 선택 전제 |
| --- | --- | --- | --- |
| A. 현재 횡단면 선별의 적용 검토 **제안** | 조사 시점 BP 임계값 라벨에 대한 **입력 기반 위험군 선별 신호**. 현재는 연구 집계와 준비 중 화면만 제공 **확정** | [8feature 의미](model-input-adapter-contract.md)와 제품 수집 방식의 동등성, 지원 대상 결정, 승인된 adapter·고정 파이프라인·artifact·실패 차단 구현 필요 | 아래 품질/외부 검증 및 단회 test 게이트. 현재 연구 결과만으로 한국 사용자를 지원하지 않음. 미래 발병 요구를 이 경로로 대체하는 수용은 **미정** |
| B. 미래 발병 가능성 연구 **제안** | 아직 사건이 없는 기준 시점 이후, 합의한 기간 안의 새로운 사건을 다루는 별도 연구 목적. 현재 라벨로 제공 불가 **확정** | 대상 질환·기준 시점 비사건 정의·예측 기간·사건 판정/시점·추적 종료·탈락/검열을 가진 종단 자료, 사용 권한과 별도 라벨/feature/모델 계약 필요. 현재 제품 기록을 즉시 연구 자료로 쓰지 않음 | 사건 수/추적 완결성/검열·시간 누수·동일인 분리, 기간에 맞는 판별·calibration 및 외부 검증 계획 필요. 지표·방법·표본 요구는 **미정**. 기존 이진 CONFIG/evidence를 이름만 바꿔 재사용하지 않음 |
| C. 개인별 신호 변화 추이 연구 **제안** | 기록 추이는 이미 있지만 모델 신호의 변화율은 없음 **확정**. 동일 모델에서 입력이 달라진 출력과 실제 미래 위험 변화는 구분 | A 또는 B 중 신호 의미를 먼저 선택. 반복 측정 시점/간격·측정 방식·모델 버전 고정, 결측·이전값·분모 0/작은 값 처리, 반복 측정 자료와 변화의 해석 계약 필요 | 측정 오차/반복성·개인 내 변화 타당성·장기 결과의 연결을 별도 평가. A의 확률 차이를 발병 변화나 챌린지 효과로 해석 불가. 단순 차이/변화율의 표시 여부도 **미정** |

A를 추진하더라도 기록 서비스·연구 보고가 발주 요구 전체를 충족한다고 처리하지
않는다. B/C는 A의 단순 화면 확장이 아니다. 효과를 주장하려면 별도의 인과적
연구 설계가 필요하며 이번 어느 경로도 그 주장을 승인하지 않는다.

## 자료의 역할과 재사용 경계

| 자료 | 유지하거나 검토할 수 있는 역할 | 대체할 수 없는 역할 / 다음 접근 조건 |
| --- | --- | --- |
| 승인된 세 집계 JSON | 기존 준비·비교·조건부 불확실성의 공개 근거 **확정**. JSON verifier로 참조·구조·산술을 다시 확인 가능 | 새 실제 예측 재계산, 모집단 성능이나 미래 발병 근거가 아님. 원본·CONFIG·실행 SHA 유지 |
| 기존 frozen train | 별도 승인 후 A의 고정 fit 또는 사전에 정한 train 내부 보정 설계에 활용하는 경로 **제안** | 지금 접근하지 않음. 후속 fit/보정 실행은 별도 CONFIG·provenance/evidence이며 기존 실행 결과를 덮어쓰지 않음 |
| 이미 본 validation | 관측된 비교의 보고 및 이후 설계에서 이미 본 선택 자료임을 공개 **확정** | 새 독립 검증, 보정 fit과 그 독립 평가의 겸용, 기준의 사전 설정 근거가 될 수 없음 |
| 잠근 test | 아래 사전 고정·별도 승인 후 한 번의 최종 내부 평가 **제안** | 계획 단계의 파일 열람/해시 금지. 선택·보정·튜닝·기준값 결정에 사용하지 않음 |
| 새 한국 대상 자료 | A에는 동등한 입력 수집 및 같은 시점 라벨을 가진 외부 평가 자료, B에는 추가로 종단 사건/추적 자료, C에는 반복 측정 자료 필요 **확정** | 자료원·접근권·동의/보관 정책·중복 대상 여부·모집 경로·표본 충분성은 **미정**. 공개 자료라는 이유만으로 목적 적합성을 인정하지 않음 |

새 자료를 찾을 때는 파일을 먼저 내려받는 대신 문서만으로 대상·시점·질문·측정·
라벨·추적·사용 조건을 대조한 후보표를 검토한다. 한국 자료의 이름이나 링크만으로
8feature 대응 또는 미래 사건이 있다고 가정하지 않는다. 기관별 자료 허용과
연구 데이터 거버넌스는 제품의 건강정보 보관 금지 경계와 분리해 별도 검토한다.

## 후속 평가를 실행 가능한 명세로 만드는 순서

아래는 **미실행 설계**다. 새로운 모델·보정 실험이나 임계값 탐색을 승인하지 않는다.

| 순서 / 검토 단위 | 실행 전에 고정할 명세·산출물 | 실패 또는 근거 부족 때 |
| --- | --- | --- |
| 1. 입력·대상 | [adapter 인계 조건](model-input-adapter-contract.md#후속-구현-인계-조건), 지원/제외 및 측정·질문 버전, 수집 부담과 미지원 안내 | 미확정 입력을 결측으로 바꾸지 않고 해당 요청/범위를 차단; 질문을 바꾸면 별도 버전으로 검토 |
| 2. 전체·subgroup 품질 | 목적/대안·오탐/미탐의 영향·예상 사용 빈도, AUROC/AP/Brier와 calibration의 역할, 목표 정밀도에 근거한 표본/사건 수, 성별·연령 및 새 지원 대상 그룹의 판정 규칙 | 지표가 나오더라도 표본 부족·산출 불가·미정 기준을 통과로 취급하지 않음. 60–80 코드 그룹의 기존 한계를 지원 축소만으로 숨기지 않음 |
| 3. 보정 필요성·데이터 역할 | 보정 없음과 승인된 후보 방식의 비교 필요성, 후보 수/선택 규칙, 아래 학습·보정·선택·최종 평가 역할, bin/구간·공개 규칙 | Brier 감소만으로 보정 성공 판단 금지. 낮은 예측 구간 및 그룹별 calibration이 부족하면 출시 보류; test로 보정 fit 금지 |
| 4. 외부 검증 | 목적에 맞는 독립 대상/기관/시점, 원자료 질문과 번역·측정 동등성, 모집/선택·결측·유병 비율 차이, 중복/누수 방지, 사전 표본/오차·공개 계획 | 동등한 feature/라벨이 없으면 외부 검증으로 계산하지 않음. 외부 자료로 보정/선택했다면 그 부분은 개발 자료로 표시하고 독립 평가를 별도로 확보 |
| 5. 최종 잠금·test | 선택 승인, 고정 fit·전처리·보정 유무·임계값·전체 평가/실패 규칙·provenance 및 독립 검토 기록 | 아래 단회 절차의 미정·미서명 항목이 있으면 test 접근 금지. 불리한 결과 뒤 같은 test로 재승인하지 않음 |

기존 10개 동일 너비 bin, 최소 20행 공개 제한, 작은/빈/단일 클래스 처리와
paired bootstrap 계약은 기존 증거를 읽을 때 그대로 유지한다. 새로운 평가의
bin·구간/다중 비교·정밀도 기준을 바꾸려면 사유와 별도 버전을 **실행 전에**
검토한다. 기존 validation을 보기 전에 정한 규칙이라고 표현하지 않는다.

공식 문서 대조(2026-09-06): 해당 주기의 [CDC P_DEMO](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/P_DEMO.htm)는
80+ top-code 및 조사/가중치 맥락을 설명한다. 이 정보가 한국 대상 검증을 대신하지
않는다. 고정 환경의 [scikit-learn 1.8 calibration 문서](https://scikit-learn.org/1.8/modules/calibration.html)는
Brier가 판별·calibration 등을 함께 반영하므로 감소만으로 calibration 개선을
단정할 수 없고, 보정 fit과 모델 fit의 자료 분리가 필요함을 설명한다. 이 원칙을
참조했으며 새 라이브러리·보정 설정을 선택하거나 실행하지 않았다.

## 완료 범위와 판정 의미

- #217: #218 병합 및 Windows/Linux 합성 CI로 구현 범위 완료·종료.
- #219: #220 병합, 승인 JSON 원본 보존과 Windows/Linux verifier CI로 증거 공개
  범위 완료·종료. 두 종료 모두 전체 모델 검증·출시 완료를 뜻하지 않는다.
- 데이터 준비, 실제 비교, 탐색적 불확실성의 승인 집계는 저장소에 존재한다.
  현재 모델 상태는 `exploratory_uncertainty_not_promoted`다.
- **충족**은 표의 한정된 조건에 증거가 있다는 뜻, **미충족**은 필요한 산출물이나
  검증이 없다는 뜻, **미정**은 판단 기준/지원 범위/승인자가 확정되지 않았다는
  뜻이다. 충족 항목 개수로 종합 출시를 승인하지 않는다.

아래 승인 주체는 필요한 역할이며 실제 담당자 지정이나 서명을 대신하지 않는다.
프로젝트 책임자(사용자)가 역할별 책임 있는 검토자를 지정해야 한다. 미지정·미서명은
승인이 없는 상태다. 데이터/ML 담당자는 증거를 작성하고, 독립 통계 검토자는
방법과 불확실성을, 분야 안전성 검토자는 오탐·미탐의 사용상 영향을, 제품/UX
담당자는 대상·문구·사용 맥락을 검토한다. 운영 책임자는 운영 승인에 별도 서명한다.

기준의 근거가 없으면 미정을 유지하고 test 접근 전에 책임 있는 검토를 마친다.
기존 validation은 이미 관측했으므로 이후 선택·설계의 영향을 공개한다.

## 향후 test: 고정 후 별도 승인된 한 번의 평가

1. 데이터 접근 없이 실행 계획을 작성한다. 지원 대상·라벨·8feature 의미·질문/
   adapter 버전, 선택 모델 및 고정 fit/재현 절차, 전처리(결측 통계 포함),
   calibration 유무/방식, signal_band 임계값, 모든 CONFIG/lock/commit과 frozen
   partition 역할을 식별한다. 최종 fit은 test 이전 별도 승인 작업으로 고정하며,
   test 평가 후 재학습한 다른 모델에 결과를 재사용하지 않는다.
2. 평가 지표(전체 AUROC/AP/Brier, calibration, 성별/연령 및 승인 대상 subgroup),
   bin/불확실성 방식, 작은/빈/단일 클래스 처리, 표본 충분성, 공개 allowlist,
   기준값 또는 판단 규칙의 근거, 실패·산출 불가·표본 부족 시 조치를 명시한다.
   현재 bootstrap 계약을 test에 자동 적용하지 않는다. test 목적의 구간/다중
   비교 규칙은 검토자가 별도로 확정해야 하며 현재 미정이다.
3. 선택 모델·전처리·임계값·지표·판정/실패 조치와 provenance를 변경 불가한
   사전 고정 패키지로 commit하고, 통계/분야 검토자 및 사용자의 별도 실행
   승인을 기록한다. 미정 항목·미서명 항목이 있으면 test는 열거나 해시하지 않는다.
   고정된 기존 metadata 참조는 계획 단계에서 사용할 수 있다.
4. 승인된 실행자만 기존 held-out test를 한 번 평가한다. 이때 처음 수행할 입력
   해시/스키마 확인, 예측, 집계 검증 및 접근 기록 절차를 패키지에 포함한다.
   개별 데이터·예측·모델은 공개하지 않는다. 집계 검증과 사람 품질 판단을 분리한다.
5. 결과가 불리하거나 부족하면 출시 보류·범위 제한 검토로 종료한다. test 수치에
   맞춰 모델/보정/임계값/통과선을 바꾸지 않는다. 같은 test를 다시 사용해 선택
   모델의 반복 승인 근거를 만들지 않는다. 변경이 필요하면 기존 test를 이미 본
   평가 자료로 표시하고 새 독립 평가 자료와 별도 설계를 확보한다.
6. 기술 실패도 성공으로 처리하거나 자동 재시도하지 않는다. 안전한 실패 기록을
   보존하고 test가 노출됐는지 독립 검토한다. 재접근/재실행을 이 계약이 자동
   승인하지 않는다. 결과 노출 시 같은 test로 튜닝·재승인하는 경로는 금지한다.

이 절차는 test 실행 명령이나 운영 승인이 아니다. Test 결과 한 번이 통과하더라도
외부/한국 검증·입력 계약·운영 승인 등 다른 미충족 조건을 대체하지 않는다.

## 보정 실험이 필요할 때의 후속 설계 조건

이번에는 보정을 실행하지 않는다. 이후 계획은 최소한 **학습**(모델·전처리 fit),
**보정**(고정 모델의 확률 변환 fit), **선택**(보정/모델/임계값 비교),
**최종 평가**(잠근 test 또는 새 외부 평가)의 역할과 행별 겹침을 명시해야 한다.
같은 행을 보정 fit과 보정 성능의 독립 평가로 사용하지 않는다. Train 내부
분할이나 cross-fitting을 택한다면 fold/seed, out-of-fold 예측 생성, 전처리 fit
범위, 최종 fit·선택 절차를 사전에 고정한다. 기존 validation을 선택에 다시 쓰면
이미 관측한 선택 자료임을 공개하며 새 독립 평가처럼 취급하지 않는다.
Test를 보정/선택에 사용하거나 새 역할 분할을 이번 작업에서 만들지 않는다.
방식·데이터량·표본 적정성과 누수 방지는 통계 검토자 승인 후 별도 실행한다.

## 향후 artifact·metadata·반복 입력 계약

현재 [metadata scaffold](../app/core/model_artifact.py)는 model_version,
split_digest, features, artifact_sha256만 가진다. [직렬화 scaffold](../scripts/model/train_artifact.py)의
존재는 승인된 artifact가 있음을 뜻하지 않으며 그 명령을 출시 절차로 사용하지
않는다. 다음 필드를 요구하는 확장 명세/검증은 후속 구현 전 검토해야 한다.

- 모델 종류·fit/실행 commit·학습 provenance, lock/CONFIG digest 및 artifact hash.
- 정확한 feature 순서·semantics/questionnaire/adapter 버전·단위·범주/결측 규칙,
  fitted 전처리 식별과 hash. 개별 fill values는 공개 metadata/로그에 넣지 않는다.
- signal_band 임계값·확률 해석·calibration 여부/버전, 선택/평가 evidence 참조,
  지원/제외 대상, 승인 주체·승인 범위·일자와 모델 버전의 연결.
- 같은 정규화 입력·동일 artifact/환경에서 같은 확률·band·버전이 나오는 합성
  반복 검증과 API 통합 증거. 수치 허용오차는 실행 환경 근거로 후속 명세에서
  먼저 고정한다. 값 반복성은 품질의 충분성과 별도다.
- hash·feature/semantics·CONFIG·임계값 불일치, 미지원/누락 입력, 미승인 artifact에서
  점수 없이 차단하는 검증. artifact 환경 변수만으로 route를 활성화하지 않는다.

[모델 카드](model-card.md)와 [입력 adapter 초안](model-input-adapter-contract.md)은
이 판정의 근거 문서다. 현재 실제 adapter·artifact·성공 API·모델 운영은 활성화하지
않고 기존 503 model_not_ready 및 no-score 동작을 유지한다.
