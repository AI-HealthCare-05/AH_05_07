Increment B3 — finite-reference comparator

이 화면은 연구 목적의 정적 목업입니다. 실제 사용자 입력을 받지 않으며, 실제 참가자 데이터를 노출하지 않습니다. 모든 숫자 예시는 합성(synthetic)입니다.

무엇을 비교하는가?

동결된 연구 참조 데이터 G6 validation product-complete subset (N=869)에서 같은 동결 모델로 계산한 내부 연속 출력의 상대적 위치입니다.

이것은 아닙니다:

  • 질환이 있을 확률
  • 나이·성별이 비슷한 사람들과의 비교
  • 건강 상태의 좋고 나쁨
  • 진단 또는 치료·예방 효과

Arm A
현재 스타일 — 내부 연속 출력

연구/개발 미리보기

내부 연속 출력 · 0.635

모델의 내부 연속 출력값입니다. 질환이 있을 확률을 뜻하지 않습니다.

Arm B
이름 붙은 유한 참조, 텍스트 백분위

연구 참조 데이터에서의 모델 출력 위치

82백분위

869건의 동결 참조 기록 중 약 82% 위치에 해당하는 출력입니다.

이 숫자는 질환이 있을 확률 82%가 아닙니다. 나이·성별이 비슷한 사람들과 비교한 값도 아닙니다.

Arm C
분포 마커 — 백분위 숫자 없음

참조 데이터 분포 위에 현재 합성 출력을 표시합니다.

0 합성 출력 위치 100

숫자 없이 위치만 표시합니다. 색상만으로 의미를 전달하지 않습니다.

Arm D
100개 위치 설명

참조 데이터의 모델 출력 분포를 100개의 위치로 나누면 약 82번째 지점입니다.

이 표현이 오히려 “82% 확률”로 오핼될 수 있는지 평가해야 합니다.

Arm E
비교 없음

내부 연속 출력의 출처와 한계만 설명합니다.

연구/개발 미리보기 · 내부 연속 출력

이 값은 연구 참조 데이터와 비교한 위치가 아닙니다.

이핵 게이트

각 표현을 본 사용자가 다음을 구별할 수 있어야 합니다. “모르겠다”는 정답으로 처리하지 않습니다.

  • 아니다 — 82백분위는 질환이 있을 확률 82%를 뜻하는가?
  • 아니다 — 나이·성별이 비슷한 사람만 비교한 것인가?
  • 아니다 — 건강상태가 나쁜 사람 중 상위 18%를 뜻하는가?
  • 아니다 — 이 숫자는 진단인가?
  • 아니다 — 숫자가 낮아지면 생활습관 때문에 건강이 좋아졌다는 뜻인가?
  • 동결 참조 기록에 같은 동결 모델을 적용한 출력 분포 — 실제 비교되는 것은 무엇인가?

합성 예시 상세

사용된 합성 내부 연속 출력: 0.635

  • 가중치 미적용 유한 순위: 77.56백분위
  • 조사 가중치 적용 유한 위치: 82.08백분위

두 방식의 최대 차이는 약 8.14 pp입니다. B/B2 결과를 숨기지 않고 보여줍니다.
