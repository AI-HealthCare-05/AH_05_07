## Boundary

This provenance permits candidate metadata intake and continued review.

It does not:

- overwrite an existing production binary
- modify an existing immutable R2 object
- create a runtime URL
- extend `CompanionSpecies`
- add an active registry entry
- change a presentation profile
- approve browser or device performance
- approve final art quality
- authorize production promotion

Production promotion remains a separate decision.
