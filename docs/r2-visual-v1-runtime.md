# SK7 R2 visual v1 hold boundary

The public R2 release at `https://sk7-assets.gomdory.com/visual/v1/` remains
available for reviewed delivery, but is not currently bound to the CSS-first
SK7 journey. It does not carry UI copy, state, controls, or health-record
content.

## Held allow-list

- The desktop/mobile backgrounds and five state characters remain approved
  delivery candidates only; no source is currently rendered by the app.
- The app uses no whole-screen PNG, utility PNG, idle, focus, or motion asset.

## Failure boundary

The CSS Calm Clay scene, live HTML wording, navigation, forms, and save
controls have no runtime image dependency. A future visual binding must prove
this boundary again with synthetic fixture data before release.

## Delivery baseline

The operator confirmed R2 bucket `sk7-assets-prod`, custom domain
`sk7-assets.gomdory.com`, `visual/v1/`, manifest MIME/CORS/cache policy, and
the cache rule. CSS is the current implementation, not merely an image
fallback; a future asset integration needs a new responsive visual review.
