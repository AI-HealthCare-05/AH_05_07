# SK7 입력 adapter 계약 초안

Issue #221의 초안을 고도화 Issue #230에서 구현 인계 조건까지 구체화한 설계 문서다.
기준은 PR #227 병합 `c46c772486a30319e594dbb9cf555263d5fba1a9`이며,
실행 가능한 adapter/DTO/OpenAPI 변경이 아니다.
원문 직접 대조 후 보완한 질문과 별도 발견 사항은
[입력 질문 검토 패키지](input-question-review.md)에 기록한다. 한국어 번역·지원 대상
승인은 여전히 대기이며 이 문서의 데이터 계약을 변경한 것은 아니다.
[semantics version 2](data-feature-semantics.md)와 manifest의 순서는
`RIAGENDR, RIDAGEYR, BMXBMI, PAQ605, PAQ620, SMQ020, ALQ111, SLD012`이다.
[legacy DTO](../app/dtos/risk_signal.py)는 sex 1..2, age_years 18..120,
bmi 10..80, physical_activity_days 0..7, smoking_status 1..3,
alcohol_frequency 0..7, sleep_hours 0..24를 받지만 실제 의미 동등성을 보장하지
않는다. [현재 route](../app/apis/v1/risk_signal_routers.py)는 검증된 요청에도
503 model_not_ready를 반환한다. 잘못된 요청의 422 동작도 유지한다.
현재 web은 기록/챌린지와 신호 준비 중 화면이며 이 모델 설문에 연결되지 않았다.

## 원자료 의미와 현재 입력의 대조

아래 범위는 기존 manifest의 분석 계약이다. 모든 대응은 현재 **미지원**이며,
후보 대응이 있다는 뜻을 활성화 승인으로 읽지 않는다. 원문 질문의 한국어
의미 요약은 [기존 semantics와 연결된 CDC codebook](data-feature-semantics.md)에
근거하며, 아래 질문 초안은 검증된 번역이 아니다.

| Feature | 원자료 의미 | 코드·단위·유효 범위 | 결측 표현 | 기존 모델 전처리 | 현재 제품/DTO 대응 판정 |
| --- | --- | --- | --- | --- | --- |
| RIAGENDR | 조사에 기록된 성별 범주 | 1/2 범주; 연속 크기 아님 | 원자료 null → -1; 특수 결측 코드 없음 | 고정 [-1,1,2] one-hot | 미지원. sex 숫자는 후보이나 수집 질문과 코드 동등성 미검토. 회원 gender/정체성에서 추론 금지 |
| RIDAGEYR | screening 당시 연령; 80은 80+ | 연 단위 정수 코드 18..80 | 준비에서 누락·범위 밖 제외 | 연속형, train 중앙값 기제; 스케일링 없음 | 미지원. age_years 18..120과 다름. 80+를 정확히80세로 해석 금지. 미래 adapter의 명시적 top-code와 지원 대상 승인 필요 |
| BMXBMI | 측정 기반 BMI | kg/m², SK7 분석 범위 10..80 | 준비에서 누락·범위 밖 제외 | 연속형, train 중앙값 기제; 스케일링 없음 | 미지원. bmi 범위만 일치. 측정/산출 방식·단위·측정 시점 확인 필요; 자기보고와 측정값의 동등성 미확보 |
| PAQ605 | 일·무급노동·집안일·정원일 중 연속10분 이상 격렬한 활동 | 1 예 / 2 아니오 | null 또는7/9 → 결측 → -1 | [-1,1,2] one-hot | 미지원. 운동 일수나 챌린지 걷기 이행을 변환할 수 없음 |
| PAQ620 | 일·집안일 등에 연속10분 이상 중간 강도 활동 | 1 예 / 2 아니오 | null 또는7/9 → 결측 → -1 | [-1,1,2] one-hot | 미지원. PAQ605와 별도 질문; physical_activity_days를 두 feature에 복제 금지 |
| SMQ020 | 평생 담배를 합계100개비 이상 피운 경험 | 1 예 / 2 아니오 | null 또는7/9 → 결측 → -1 | [-1,1,2] one-hot | 미지원. 현재 흡연 상태나 빈도로 평생 기준을 추론할 수 없음 |
| ALQ111 | 맛보기/작은 모금 제외 평생 술을 한 잔 이상 마신 경험 | 1 예 / 2 아니오 | null 또는7/9 → 결측 → -1 | [-1,1,2] one-hot | 미지원. 현재 음주 빈도, ALQ101과 동의어 아님 |
| SLD012 | 평일/일하는 날 주 수면 구간, 평소 잠든·잠에서 깬 시각에서 유도 후 반시간 단위 반올림; 침대에 든/나온 시각과 구분 | 2는3시간 미만, 3·3.5·…·13.5, 14는14시간 이상 | null → -1; 2/14는 결측 아님 | 각 공개 코드와 -1을 one-hot; 연속 시간값으로 사용하지 않음 | 미지원. sleep_hours 0..24는 낮잠 포함 여부·주 수면·반올림/경계 의미가 불명확. 2를2시간,14를정확히14시간으로 변환 금지 |

공통 파이프라인은 feature 순서를 보존하고 선언된 고정 범주를 one-hot 한다.
알 수 없는 범주는 오류다. 중앙값은 train에서만 고정하며 inference에서 새
통계를 계산하지 않는다. 입력 의미 불일치를 -1로 바꾸어 전체 입력을 강제로
수용할 수 없다. 준비 데이터의 결측 표현과 제품의 미지원 입력은 다른 상태다.

## 필요한 추가 질문·문구: 검토 초안만

제품 담당자와 데이터 semantics 검토자가 원문·한국어 번역·이해도 검사와
응답 코딩을 승인해야 한다. 현재 UI/API에 넣지 않는다.

- 성별: 원자료 1/2의 수집 기준과 한국어 질문의 대응을 먼저 결정한다. 정체성이나
  기존 회원 프로필을 대신 쓰지 않는다. 대응되지 않는 응답/대상은 미지원으로
  안내하며 임의로 둘 중 하나에 배정하지 않는다.
- 연령: “현재 만 나이는 몇 세인가요?”는 후보 문구다. 조사 screening 연령과
  사용 시점의 차이, 80세 이상을 묶는 설명·지원 범위를 검토한다. 향후 승인된
  adapter에서만 80+를 코드80으로 명시적으로 정규화하고 원래 정확한 나이를
  모델 feature로 추가하지 않는다.
- BMI: “측정한 키와 몸무게로 산출한 BMI(kg/m²)” 및 측정 시점 확인 문구를
  검토한다. 추가 측정 정보의 수집·보관 최소화는 별도 검토한다. 기존 bmi 숫자만
  보고 측정 근거가 있다고 간주하지 않는다.
- PAQ605: “평소 한 주에 유급·무급 일·집안일·정원일 등을 하면서, 숨이나 심장박동이 크게 증가하는
  격렬한 활동을 한 번에10분 이상 하나요?”
- PAQ620: “평소 한 주에 유급·무급 일·집안일 등을 하면서, 숨이나 심장박동이 약간 증가하는 중간 강도
  활동을 한 번에10분 이상 하나요?” 운동 일수 질문과 분리한다.
- SMQ020: “지금까지 평생 담배를 합계100개비 이상 피운 적이 있나요?”
- ALQ111: “맛보기나 작은 모금을 제외하고, 평생 술을 한 잔 이상 마신 적이 있나요?”
  원문 예시 맥주12oz/와인5oz/증류주1.5oz와 한국어 용량 안내의 대응은 별도 검토한다.
- 수면: “평일 또는 일하는 날, 주로 잠드는 시각과 잠에서 깨는 시각은 언제인가요?”를
  후보로 검토한다. 낮잠, 자정 넘김, 교대근무, 정확히 경계에 있는 응답,
  반시간 반올림 tie 처리의 원자료 동등성을 확정하기 전 변환하지 않는다.
- 예/아니오/모름/응답하지 않음의 표시·코드 매핑을 검토한다. 모름이나 거절을
  아니오로 바꾸지 않는다. 실제 null 허용 feature와 화면 안내는 승인 전 미정이다.

## 향후 adapter 구현에 필요한 계약

질문 버전·지원 대상·단위·응답과 결측 코딩·정규화 버전·semantics version 2·
feature 순서를 하나의 승인 명세로 고정한다. 숫자형 문자열/비유한 값/범위 밖/
예상 밖 필드/모순 응답은 조용히 clamp·추정하지 않고 거부한다. 80+ top-code는
승인된 의미 변환일 때만 예외이며, 임의 범위 자르기와 구분한다. 필수 연령/BMI
누락을 중앙값으로 우회하지 않는다. source에 없는 성별 대응·자기보고 BMI·
교대근무 수면 등 미확정 범위는 지원 불가로 남겨 둔다.

혈압 라벨 입력·혈압 파생값·SEQN·챌린지 이행·식별자는 모델 벡터에 넣지 않는다.
원문 자유서술 병력이나 원본 문서를 수집하지 않는다. 향후 오류/분석 로그에도
개별 입력값을 남기지 않는다. 모델·전처리 artifact에 고정된 규칙을 그대로
사용하며 validation/test 통계나 새 요청 집계로 보간하지 않는다.

승인 후 별도 구현에서 경계 코드, 결측과 미지원의 구분, 80+ top-code, 잘못된
범주 거부, 같은 정규화 입력의 반복 일관성을 합성 fixture로 검증해야 한다.
이번 문서는 adapter 실행 경로나 API 성공 응답을 만들지 않는다.

## 후속 구현 인계 조건

현재 **확정**된 것은 기존 8feature·순서·semantics와 실패 차단 경계다. 아래
인터페이스는 **제안**이며 DTO/HTTP 응답을 확정하거나 활성화하지 않는다. 질문
화면의 작동·표시 확인과 한국어 자연화는 의미·측정·지원 대상 승인이 아니다.

| 결정할 묶음 | 해소에 필요한 근거·결과 | 근거가 없을 때 |
| --- | --- | --- |
| 성별·지원 대상 | RIAGENDR의 조사 범주와 제품 수집 개념을 명시한 검토, 범주 밖·응답 거절 처리 및 지원/제외 대상 | 정체성·프로필에서 추론하지 않고 미지원. 코드 1/2 강제 배정 금지 |
| 나이·측정 BMI | 기준 시점, 80+ top-code 설명·지원 결정, 측정 키/체중의 단위·시점·산출/반올림 근거와 최소 수집 범위 | 정확한80세와80+를 동일한 사람 특성으로 설명하지 않음. 숫자만 있는 BMI는 측정 동등성 미확보 |
| 업무·평생 경험 | 업무 맥락/강도/연속10분, 평생100개비·한 잔의 제품/용량 범위를 보존한 한국어 이해도·응답 코딩 검토 | 운동 일수·현재 흡연/음주 빈도에서 역변환 금지. 문장 자연스러움만으로 통과하지 않음 |
| 수면 파생 | 잠듦/깸과 주 수면 정의, 반올림 tie·경계 순서·편집 절차, 자정/주간/가변 일정에 대한 문서화된 대응 | 확인되지 않은 시간차·2h45m/13h45m·교대 일정을 임의 코딩하지 않음. 해당 입력은 미지원 |
| 모름·거절·누락 | feature별 허용 여부, 공개 변수의 특수 결측과 제품 응답 상태의 대응, 입력 완전성 안내 | 미지원과 결측을 합치지 않음. 연령/BMI의 필수 누락을 train 중앙값으로 우회하지 않음 |

검토 인계는 다음 순서로 진행한다.

1. 질문/응답 선택지 버전, 원문 URL/확인일, 의미 대조의 미해결 항목, 지원 대상과
   측정 방식을 하나의 검토 표에 고정한다. 표는 [질문 패키지](input-question-review.md)의
   근거를 링크하며 별도 복제 설문을 만들지 않는다. 대상 사용자 이해도 검토의
   동의·수집 최소화·방법은 별도 설계하며 건강값을 이번 화면에서 수집하지 않는다.
2. 승인된 항목에 한해 원래 응답 상태를 보존한 typed 입력 → 명시적 정규화 →
   정확히8개 feature 순서의 벡터라는 순수 변환 명세를 작성한다. 원본 응답·개별
   벡터를 저장/로그로 남기지 않고 전처리 fit이나 모델 호출을 포함하지 않는다.
3. 변환 결과를 `accepted` / `invalid` / `missing_required` / `unsupported`로
   구분하는 내부 결과 타입을 **제안**한다. 이는 새 HTTP status 계약이 아니다.
   `accepted`는 승인된 입력 의미에만 적용하고, 모델 준비·품질·출시 승인을 뜻하지
   않는다. 모름/거절을 허용하더라도 해당 feature의 승인된 결측 규칙에만 매핑한다.
4. 8feature별 정상/경계/모름/거절/누락/미지원 사례, 평생과 현재가 다른 응답,
   운동만 아는 응답, 측정 근거 없는 BMI, 정확한80세/80+, 미정 수면 경계를 합성
   fixture로 고정한다. extra·문자열 숫자·NaN/Infinity·모순/범위 밖 거부와 feature
   순서, BP/SEQN 제외, 동일 정규화의 반복성을 실행 검증한다. 의미 타당성은
   합성 코드 검사와 별도로 사람이 검토한다.
5. 질문·adapter·semantics·feature·전처리 버전의 정합성을 검증하는 후속 PR을
   먼저 검토한다. UI/API 연결과 artifact 활성화는 [출시 판정](model-release-readiness.md)의
   별도 승인 이후다. 모든 대응이 미승인인 현재는 503 model_not_ready를 유지한다.

원문 재확인(2026-09-06): [P_BMX](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/P_BMX.htm)는
측정 키/체중에서 산출하고 소수 첫째 자리로 반올림한 BMI를 설명한다.
[P_SLQ](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2017/DataFiles/P_SLQ.htm)는 주 수면의
잠듦·깸에서 유도하며 낮잠을 포함한24시간 총 수면이 아닐 수 있음을 명시한다.
이 사실이 미확정 반올림 tie나 제품 자기보고 입력의 대응 근거를 채우지는 않는다.
