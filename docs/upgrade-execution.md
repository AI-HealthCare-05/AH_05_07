# SK7 고도화 실행 기록

실행 기준은 PR #227 병합 `c46c772486a30319e594dbb9cf555263d5fba1a9`이다.
시작 시 origin/main과 일치했고 사용자 작업 트리는 변경하지 않았다.
[1회차 마감](mvp1-closeout.md)은 계속 진행 중이다. 고도화 결과나 캐릭터 제작은
발주 범위 수용·입력 의미·adapter·모델·운영 출시 승인을 대신하지 않는다.
기존 제출 검토본과 승인 evidence·manifest·CONFIG·lock을 보존한다.

관리한다. 하위 에이전트의 한 차례 사용량 제한 중단 후 저장된 변경에서 재개했다.
중단을 작업 완료로 처리하거나 사용량 초기화 크레딧을 임의 사용하지 않았다.

## 제작·보관 경계

- 로컬 실행 폴더에는 실행 상태, 재개 지침, 실패 기록, 파일 크기·SHA-256·도구
  버전·생성 소스·검증 범위를 기록한다. 원본·GLB·렌더·영상은 외부 로컬 폴더에
  둔다. 저장소에는 제작 소스와 작은 계약·검사 기록만 반영한다.
- Blender 4.5.13 LTS Windows portable을 공식 배포처에서 받아 공식 SHA-256과
  대조했다. 관리자 설치나 기존 Python/Node/프로젝트 lock 업그레이드는 없다.
- 내장 이미지 생성의 곰 시안은 제작 참고용이다. 사용자 이미지 승인 기록은
  없으며, 이미지 시안을 3D 완성 자산으로 세지 않는다. 유료 3D 생성은 사용하지 않는다.
- 모델링·리깅·내보내기 단계마다 원본을 저장하고 실패 버전을 보존한다.
  곰 첫 버전의 팔 가중치 결함은 실제 포즈 렌더에서 발견했으며 수정 전 결과는
  품질 통과 수량에서 제외한다.
- 같은 디스크의 checkpoint는 독립 백업이 아니다. 승인된 별도 백업 위치와
  외부 자산 업로드 대상은 아직 없으므로 독립 백업·외부 공개를 주장하지 않는다.

## 보존하는 미완료 조건

만료는 시작하지 않았으며, 2026-09-06 시작을 가정해도 10월6일 이후라 9월21일
제출 일정과 맞지 않는다. 별도 로컬 정책 검증의 수용 여부는 외부 판단이다.
발주사 질의는 미발송, 제출 시트 대조·입력/모델 승인·발주 범위 수용·사용자 최종
검토는 대기다. 종료 알림 자동화는 중지 상태를 유지한다.

실제 모델/데이터 실행·test 접근/해시·보정·bootstrap·직렬화·승격·배포는 없다.
제품은 `model_not_ready`를 유지한다. PR 병합은 사용자가 한다.
